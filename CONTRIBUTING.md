# Como Contribuir

Obrigado por ajudar a melhorar o Project Backup Pilot.

Este projeto foi criado e e desenvolvido por **Rafael Petri**.

## Formas De Contribuir

- Abra issues para bugs, ideias ou melhorias de documentacao.
- Use pull requests para enviar correcoes e melhorias.
- Mantenha alteracoes focadas e faceis de revisar.
- Prefira padroes seguros.
- Nao adicione codigo que enfraqueca a protecao contra secrets.
- Teste os scripts PowerShell antes de enviar alteracoes.

## Fluxo Recomendado

1. Abra uma issue descrevendo o problema ou melhoria.
2. Faca um fork do repositorio.
3. Crie uma branch com nome claro.
4. Faca a alteracao mantendo portugues do Brasil como idioma principal.
5. Teste os scripts alterados.
6. Abra um pull request explicando o que mudou.

## Pull Requests

Pull requests sao bem-vindos, principalmente para:

- melhorar compatibilidade com Windows
- melhorar documentacao
- ampliar protecoes contra arquivos sensiveis
- adicionar modo dry-run
- melhorar logs e relatorios
- corrigir bugs reais

Mudancas que reduzem seguranca ou publicam arquivos sensiveis nao serao aceitas.

## Principios Do Projeto

- Seguranca em primeiro lugar.
- Automacao clara, sem magica escondida.
- Comportamento amigavel para Windows.
- Poucas dependencias.
- Fluxos praticos para VPS, freelancers e agencias.
