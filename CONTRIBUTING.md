# Como Contribuir

Obrigado por ajudar a melhorar o Project Backup Pilot.

Este projeto foi criado e e desenvolvido por **Rafael Petri**.

## Formas De Contribuir

- Abra issues para bugs, ideias ou melhorias de documentacao.
- Mantenha alteracoes focadas e faceis de revisar.
- Prefira padroes seguros.
- Nao adicione codigo que enfraqueca a protecao contra secrets.
- Teste os scripts PowerShell antes de enviar alteracoes.

## Principios Do Projeto

- Seguranca em primeiro lugar.
- Automacao clara, sem magica escondida.
- Comportamento amigavel para Windows.
- Poucas dependencias.
- Fluxos praticos para VPS, freelancers e agencias.
