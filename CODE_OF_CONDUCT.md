# Codigo De Conduta

Project Backup Pilot foi criado e e desenvolvido por **Rafael Petri**.

Este projeto aceita colaboracoes da comunidade. Para manter um ambiente saudavel, todos devem seguir estas regras.

## Nosso Compromisso

Queremos um espaco aberto, respeitoso e produtivo para pessoas que queiram aprender, usar, melhorar ou auditar o projeto.

## Comportamentos Esperados

- Tratar outras pessoas com respeito.
- Dar feedback tecnico de forma objetiva.
- Explicar problemas com clareza.
- Aceitar opinioes diferentes quando houver mais de uma solucao valida.
- Priorizar seguranca, simplicidade e utilidade real.

## Comportamentos Nao Aceitos

- Ofensas pessoais.
- Assedio ou intimidacao.
- Publicacao de dados privados, tokens, senhas ou credenciais.
- Comentarios discriminatorios.
- Spam ou autopromocao fora do contexto do projeto.

## Seguranca

Nao publique credenciais reais em issues, pull requests, prints ou logs.

Se encontrar uma falha de seguranca, reporte de forma privada ao mantenedor.
